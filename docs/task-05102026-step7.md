## Dump Semantics Note

The contextual filter dump's `AFTER.records` represents the complete candidate set with decision metadata.

Therefore:

- `AFTER.records` = all candidates after filtering/decision evaluation.
- Accepted contextual evidence = records where `decision == "accept"`.
- `contextual_added` = accepted records actually added to the EvidenceRecord lifecycle.

This distinction is informational and does not indicate a production defect.
