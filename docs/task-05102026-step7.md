## Contextual Filter Dump Semantics

`cache/evidence/contextual_filter_dump.md` remains a diagnostic dump of **all post-filter candidates**, not an accepted-only evidence list.

Within `AFTER.records`:

- `decision == "accept"` identifies candidates accepted by the contextual filter.
- `contextual_added` is the number of accepted candidates actually added to the EvidenceRecord lifecycle.
- Rejected candidates remain in the dump for auditability and filter diagnostics.

This distinction is intentional and does not alter downstream EvidenceRecord semantics.
