# Temporal Semantics Audit Checkpoint

Date: 06-10-2026
Branch: feat/evidence-enrichment-foundation

## Status

Temporal Semantics Audit: PASS.

## Contract

- `observed_at`: acquisition/observation time generated by Privacy Auditor; timezone-aware ISO-8601 timestamp required.
- `published_at`: source-reported publication date/time; optional; never inferred.
- `verification_observed_at`: time Privacy Auditor checked URL accessibility; timezone-aware ISO-8601 timestamp required.
- Event/exposure time is not represented and remains unknown unless future evidence explicitly establishes it.

## Implementation

- EvidenceRecord validates temporal fields according to their semantics.
- Source publication normalization accepts source-reported ISO date-only values (YYYY-MM-DD) without inventing a timezone.
- Invalid, ambiguous, or unsupported source publication values become missing/unknown.
- URL accessibility verification records its own observation timestamp.
- No global aggressive timestamp parser was introduced.
- No event/exposure timestamp was added.
- Temporal semantics remain separate from risk, score, or probability.

## Validation

- Full automated suite: 106 passed in 6.35s.
- Real-case fresh run: Discovery MISS, 84 base evidence records, 7 contextual records accepted, 91 final evidence records.
- Real-case cached run: Discovery HIT, 84 base evidence records, 8 contextual records accepted, 92 final evidence records.
- Discovery input fingerprint remained consistent across fresh/cached runs.
- Firecrawl rate-limit/cooldown behavior remained bounded and stopped remaining domain batches after cooldown.
- BreachDirectory rate limiting remained isolated and did not produce a false "no breach" result.
- No temporal regression was observed in the real-case runs.

## Notes

The fresh/cached contextual-count difference is attributable to external provider candidate availability before cooldown, not to temporal semantics.

No additional real-case run is required solely to force a date-only `published_at` record; that contract is covered by automated tests.
